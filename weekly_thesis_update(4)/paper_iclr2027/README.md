# ICLR 2027 paper draft

This directory contains a submission-style draft distilled from
`../evaluation/new_main.tex`. It uses the official ICLR 2027 style bundle and
keeps the submission anonymous by leaving `\iclrfinalcopy` commented out.

Build from this directory with:

```sh
make
```

The selected figures are packaged under `figures/`, and the bibliography is in
`references.bib`, so this directory builds independently of the thesis source.

Before submission, verify the author list, title, abstract, AI-use statement,
anonymity of code/data links, and the final page count. The main-text page limit
is measured before the AI-use statement and references.
